# relayme

Downloads of the RelayMeThis command-line tool.

Install (Linux, macOS):

    curl --proto '=https' --tlsv1.2 -fsS https://relaymethis.com/install | sh

Windows PowerShell:

    irm https://relaymethis.com/install.ps1 | iex

The installer checks each download against checksums served by relaymethis.com.
Releases marked pre-release are beta builds for https://beta.relaythis.me.
